## Design Explanation

### Why did you choose this class?

My interests in games is what encouraged me to make up a class like this. This class will help me manage my own game library.

### Which property is the most important? Why?

The title is the most important property as it distinguishes a game from another game in a list or a library. Without it, identifying games from each other would be difficult.

### Which method is the most useful? Why?

The most useful method is the getGameDescription(). It helps users get important description of a game.
